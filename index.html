    Use them

    The files are packed small for the web: meshopt geometry (EXT_meshopt_compression, KHR_mesh_quantization) and WebP textures (EXT_texture_webp). In three.js, give the loader the meshopt decoder.

    loader.js
    import { GLTFLoader } from 'three/addons/loaders/GLTFLoader.js';
import { MeshoptDecoder } from 'three/addons/libs/meshopt_decoder.module.js';

const loader = new GLTFLoader();
loader.setMeshoptDecoder(MeshoptDecoder);
const { scene } = await loader.loadAsync('models/desk.glb');

    A tool that cannot read those extensions needs the file unpacked first, for example with glTF-Transform: npx @gltf-transform/cli copy desk.glb desk-plain.glb.
